# 思维模型 Prompt 技能库

本技能收录 12 套高质量思维模型 Prompt，可直接用于引导深度对话与结构化思考。

## 模型清单

| 编号 | 模型 | 适用场景 | Prompt 文件 |
|------|------|----------|-------------|
| 01 | 苏格拉底提问 | 澄清困惑、找到真正值得回答的问题 | [prompts/01-socratic-questioning.md](prompts/01-socratic-questioning.md) |
| 02 | 双层解释法 | 学习新概念、小白版+专业版对照 | [prompts/02-dual-layer-explanation.md](prompts/02-dual-layer-explanation.md) |
| 03 | 反向拆解 | 从优秀范例中提炼可复用规律 | [prompts/03-reverse-deconstruction.md](prompts/03-reverse-deconstruction.md) |
| 04 | 纵横分析法 | 对产品/公司/人物/事件做深度研究 | [prompts/04-vertical-horizontal-analysis.md](prompts/04-vertical-horizontal-analysis.md) |
| 05 | 事实核查 | 验证说法、拆分事实/结论/价值判断 | [prompts/05-fact-checking.md](prompts/05-fact-checking.md) |
| 06 | 专家会诊 | 多视角分析复杂问题 | [prompts/06-expert-consultation.md](prompts/06-expert-consultation.md) |
| 07 | 第一性原理 | 从底层事实重新推导解决方案 | [prompts/07-first-principles.md](prompts/07-first-principles.md) |
| 08 | 跨领域借解 | 从其他领域借用解决机制 | [prompts/08-cross-domain-borrowing.md](prompts/08-cross-domain-borrowing.md) |
| 09 | 双向钢人论证 | 对两难决策做最强正反论证 | [prompts/09-steelman-argument.md](prompts/09-steelman-argument.md) |
| 10 | 最小实验替代空想 | 用低成本实验验证关键假设 | [prompts/10-minimal-experiment.md](prompts/10-minimal-experiment.md) |
| 11 | 挖掘隐藏天赋 | 多轮对话生成个人天赋使用说明书 | [prompts/11-hidden-talent-discovery.md](prompts/11-hidden-talent-discovery.md) |
| 12 | 人生设计术 | 多轮对话生成个人人生设计蓝图 | [prompts/12-life-design.md](prompts/12-life-design.md) |

## 使用方式

1. 根据用户需求选择对应的思维模型
2. 读取对应 Prompt 文件，将其中的【】占位符替换为用户的具体内容
3. 严格按照 Prompt 中的规则、流程和输出格式执行对话
4. 对于多轮对话类模型（01、09、11、12），严格遵守"每次只问一个问题"的节奏

## 注意事项

- 多轮对话模型需要用户参与，不要一次性输出全部问题
- 研究类模型（04、05）需要联网核查时，应使用搜索工具获取一手来源
- 所有模型的输出格式和结构应严格遵循 Prompt 中的要求
